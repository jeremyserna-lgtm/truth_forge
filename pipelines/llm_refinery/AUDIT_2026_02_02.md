## Issues Found

### 🔴 CRITICAL: JSON Parse Errors Ignored

**Location**: `processor.py` lines ~280-320

**Problem**: The `parse_json_response()` function catches JSON parse errors, logs a warning, but CONTINUES PROCESSING. Partial/corrupt data gets written to BigQuery.

```python
# CURRENT (BROKEN)
except JSONDecodeError as e:
    logger.warning(f"Failed to parse JSON: {e}")
    return {}  # Empty dict continues processing
```

**Fix Required**:
```python
# CORRECT
except JSONDecodeError as e:
    logger.error(f"JSON PARSE FAILED - STOPPING: {e}")
    raise  # Propagate error, stop processing
```

### 🔴 CRITICAL: No Duplicate Prevention

**Location**: `bigquery_loader.py`

**Problem**: Uses `WRITE_APPEND` with no deduplication. If the same conversation is processed twice (common when LLM fails mid-way and restarts), duplicates are created.

**Fix Required**: Implement MERGE statement or track processed conversation IDs.

### 🔴 CRITICAL: Missing Schema Validation

**Problem**: No validation that the output from `to_entity_unified()` matches the BigQuery schema before writing.

**Fix Required**: Add explicit schema check before any BigQuery write.

### 🟠 HIGH: Silent Ollama Failures

**Location**: `processor.py` Ollama client

**Problem**: When Ollama returns invalid JSON (which happens frequently), the error is logged but processing continues with empty/partial data.

**Evidence**: Logs showed constant JSON parse errors while data continued to be written.

### 🟠 HIGH: No Validation of Parent Chains

**Problem**: The pipeline creates entities with parent_id references but never validates:
1. That the parent entity exists
2. That the parent is the correct level (L5 should point to L6, not L8)
3. That the chain is complete (no skipped levels)

**Evidence**: Found 25,316 orphan L6 turns with no valid parent hierarchy.

### 🟡 MEDIUM: No Idempotency

**Problem**: Running the pipeline twice on the same input creates duplicates instead of updating existing records.

**Fix Required**: Implement upsert logic using `conversation_id + entity_type` as unique key.

```python
# In processor.py parse_json_response()
def parse_json_response(self, response: str) -> dict:
    """Parse LLM JSON response - FAIL FAST on errors."""
```

```python
# In bigquery_loader.py
REQUIRED_FIELDS = {
    "entity_id", "level", "entity_type", "entity_mode",

    "created_at", "updated_at"
}

def validate_record(record: dict) -> bool:
    """Validate record matches BigQuery schema."""
    missing = REQUIRED_FIELDS - set(record.keys())
    if missing:
        raise ValueError(f"Missing required fields: {missing}")
    
    if record["level"] not in range(2, 9):
        raise ValueError(f"Invalid level: {record['level']}")
    
    return True
```

### Fix 4: Validate Parent Chains

```python
def validate_parent_chain(entities: list) -> bool:
    """Ensure all parent references are valid."""
    entity_ids = {e["entity_id"] for e in entities}
    
    for entity in entities:
        if entity["parent_id"] is None:
            if entity["level"] != 8:
                raise ValueError(f"Only L8 can have null parent: {entity}")
        else:
            if entity["parent_id"] not in entity_ids:
```
