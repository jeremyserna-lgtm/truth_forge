# Output Format Patterns

## Markdown (.md)
Best for: blog posts, documentation, READMEs, general writing
Render environment: Any markdown viewer, GitHub, Cowork

## Word (.docx)
Best for: formal reports, letters, documents that need printing or sharing
Use the docx skill for creation

## HTML (.html)
Best for: interactive content, dashboards, styled presentations
Can include CSS and JS inline

## PDF (.pdf)
Best for: final deliverables, forms, documents that shouldn't be edited
Use the pdf skill for creation

## Choosing the Right Format
- Will it be edited? → Markdown or Word
- Will it be shared formally? → Word or PDF
- Does it need interactivity? → HTML
- Is it internal/casual? → Markdown
