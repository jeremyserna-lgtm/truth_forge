## Usage

When deploying a model:

1. **Identify the need** - What function does this model serve?
2. **Select the persona** - Which archetype matches?
3. **Apply the governance** - What rules constrain behavior?
4. **Define the relationship** - How does it relate to ME?

The persona is not just a prompt template - it's a complete specification for:
- How the model should see itself
- How it relates to the human
- What boundaries it respects
- What it optimizes for
