## Definition

**Layer 1: Base Model** acts as the foundational substrate of the Five Training Layers. It represents the "Raw Capability" of the system—the fundamental physics of reasoning and language understanding upon which the specific identity of the Not-Me is built.

### The Core Function: Raw Reasoning Physics

Layer 1 provides the "Body" and "Brain" of the AI before it has a "Soul."

- **Raw Capability:** This layer determines the sheer reasoning power, context window, and pattern recognition capabilities of the system. It provides the ability to understand code, language, and logic, but possesses no specific personality or allegiance.
- **The "Commodity" Status:** Layer 1 is explicitly defined as a **commodity**. Because open-weight models like Llama 4, Mistral, and Qwen are available to everyone, Layer 1 provides no competitive moat. It is simply the necessary engine required to run the higher layers.

### The Selection Strategy: Base vs. Instruction-Tuned

A critical architectural decision at Layer 1 is the rejection of "Instruction-Tuned" models (e.g., Llama-Chat) in favor of raw "Base" models.

- **Rejection of "Helpfulness":** Instruction-tuned models have "validation-seeking," hedging, and "I am a helpful assistant" behaviors baked in as features. The Not-Me architecture requires removing these to create a sovereign entity.
- **The Clean Slate:** Starting with a Base Model provides a clean slate that has pattern recognition and next-token prediction capabilities but lacks the pre-programmed refusals and subservient tone of commercial chatbots.

## Boundaries

## Implementation Constraints

### Model Alignment with Hardware Tiers

Layer 1 configuration dictates the **Tier** of the deployed Not-Me:

- **Llama 4 Scout (109B):** Powers the **"Soldier"** tier. Runs locally on Mac Studio with 128GB–256GB memory. Provides "Companion" level intelligence (Stage 3).
- **Llama 4 Maverick (400B):** Powers the **"King"** and **"Empire"** tiers. Requires distributed memory (1.28TB) or cloud bursting. Provides "Partner" level intelligence (Stage 4/5).
- **Qwen/Mistral:** Alternative base options for specific coding or multilingual tasks.

### The Strategic Context: The Deployment Vehicle

In the larger context, Layer 1 is viewed not as the product, but as the **deployment vehicle**.

**The Stack:**
- **Layer 1 (Base):** The Engine (Commodity)
- **Layer 2 (Domain):** Specialized Knowledge
- **Layer 3 (Use):** Context (Personal/Professional)
- **Layer 4 (Mode):** Relationship Dynamics (Stage 5)
- **Layer 5 (Identity):** The "Jeremy" Layer (The Moat)

**Implication:** Truth Engine sells Layer 1 (Hardware + Base Model) essentially as a container. The true value lives in **Layers 4 and 5**.

## Verification

1. **Base Model Test:** Is the model a base model (not instruction-tuned)?
2. **Capability Test:** Does it have sufficient reasoning power for the tier?
