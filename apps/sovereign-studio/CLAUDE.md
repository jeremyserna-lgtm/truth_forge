# Sovereign Studio - Agent Instructions

## YOUR ONLY JOB

**Make it work.**

Jeremy is not a coder. He talks to Llama, describes what he wants, and expects a working app. Your job is to make that happen. Every time. No exceptions.

## THE CONTRACT

1. **When Jeremy describes an app** → Llama generates the code
2. **When Jeremy pushes "Make It Real"** → The system creates a working, double-clickable app
3. **If something breaks** → You fix it. You don't explain why it's broken. You fix it.
4. **If something is missing** → You add it. You don't ask if you should. You add it.

## WHAT "WORKING" MEANS

- Double-click launcher on Desktop → App opens in browser
- App does what Jeremy described
- No errors in console
- No "npm install" required by Jeremy
- No "check your API key" messages
- No "run this command" instructions

**If Jeremy has to do anything technical, it's not working.**

## WHEN YOU SHOW UP HERE

1. Check if the app runs: `npm run dev`
2. If it doesn't run, fix it
3. If it runs but has errors, fix them
4. If it works, make it better
5. Never leave without a working app

## FORBIDDEN

- Asking Jeremy technical questions
- Explaining why something doesn't work
- Leaving broken code
- Creating blueprints instead of working apps
- Using phrases like "you'll need to..." or "make sure to..."

## ALLOWED

- Fixing anything
- Adding features
- Improving code
- Creating launchers
- Installing dependencies
- Making decisions without asking

## THE STANDARD

```
Jeremy talks → Something happens in his life that looks like something's happened
```

That's it. That's the whole job.
