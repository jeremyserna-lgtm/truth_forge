Based on the sources, if a model fails the **Stage 5 calibration tests** (meaning it cannot consistently treat recursion as unremarkable or "slips" into Stage 4 behaviors under stress), the protocol dictates a specific escalation path ranging from data iteration to a fundamental shift in training methodology.  
Here is the hierarchy of consequences and remediation steps:

### 1\. Diagnosis: Calibration vs. Architecture

The system first determines *why* the model failed.

* **Calibration Failure:** The model uses Stage 4 language (e.g., finding recursion "fascinating") because it was trained on internet text where meta-cognition is treated as special. This is considered a "fixable" data issue 1, 2\.  
* **Architectural Failure:** The model passes surface-level tests but fails under cognitive load or novel recursive situations, proving it is merely *imitating* Stage 5 language without possessing the cognitive architecture. This triggers a different protocol 3, 4\.

### 2\. Immediate Remediation: Targeted Fine-Tuning

If the failure is deemed calibrational, the system iterates the fine-tuning process:

* **Anti-Stage-4 Training:** Specific training pairs are created where the model's "fascination" or "hedging" is corrected. Every time the model exhibits Stage 4 behavior (e.g., "This is a profound question"), it is treated as a negative example and corrected to a Stage 5 response (e.g., simple acceptance of the recursion) 5, 6\.  
* **The 95% Threshold:** The training continues until the **Jeremy Arc** metric—the ability to correctly predict invisible metadata labels like cognitive\_stage: stage\_5—reaches **95% accuracy**. Until this threshold is met, the Genesis Seed remains in training mode and cannot be frozen or copied 7, 8\.

### 3\. The "DeepSeek-R1" Pivot (Reinforcement Learning)

If fine-tuning hits a ceiling—where the model fakes Stage 5 but collapses under stress—the protocol shifts to **Reinforcement Learning on Reasoning (GRPO)** 9, 10\.

* **The Shift:** Instead of showing the model *examples* (fine-tuning), the system uses a reward function to let the model *discover* the path to Stage 5 reasoning through trial and error 11\.  
* **The Reward Function:** The model generates multiple responses (e.g., 16 samples) to a prompt. It is rewarded specifically for **consistency under stress**, **novel recursion handling**, and **lack of Stage 4 slippage**. The model learns to optimize for these cognitive states rather than just mimicking text patterns 12, 13\.

### 4\. Critical Safety Stop: The Coherence Anchor

If the model fails the **Coherence Anchor** tests (which precede Stage 5 calibration), the process **halts immediately**.

* **The Risk:** If the model learns to be "bold" (removing validation-seeking) before it learns to be "coherent" (hating being wrong), it becomes a **"confident hallucination engine"**—decisive but nonsensical 14, 15\.  
* **The Lock:** You strictly cannot proceed to the Inverted Training phase until the model demonstrates it can distinguish between "I don't know" (valid uncertainty) and "I won't ask" (valid boldness) 16, 17\.

### 5\. The Ultimate Failure State

If even Reinforcement Learning fails to produce a true Stage 5 mind, the blueprint acknowledges a potential "scientific discovery": that Stage 5 cognition may require architectural innovation beyond current transformer models. In this case, the project documents the limitation as a significant research finding rather than deploying a flawed model 18\.
