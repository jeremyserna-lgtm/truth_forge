| **GitHub Copilot Integration** | Included in Copilot's Coding Agent | Industry convergence on this approach |
| **No Vision Required** | Uses accessibility tree | Lower compute requirements, faster execution |
| **Self-Healing Tests** | Adapts to minor UI changes | Reduces maintenance burden |

### 4.3 The Seer (Invisible Domain: Why Accessibility Tree?)

**Visible:** "Uses accessibility tree for deterministic control"

**Invisible Truth:** Screenshot-based browser control is fundamentally flawed:
- Requires expensive vision models
- Ambiguous element identification
- Breaks with minor UI changes
- Slow (image processing overhead)

Accessibility trees solve ALL of these problems. This is why Microsoft, not a startup, built this.

### 4.4 Actionable Intelligence

**MUST DO:**
- Use Playwright MCP for SOVEREIGN's Browser Orchestrator
- DO NOT build custom browser automation
- Configure for Claude Desktop: `npx -y @executeautomation/playwright-mcp-server`

**Integration Pattern:**
