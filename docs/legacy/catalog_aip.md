# Legacy Catalog: Adaptive Integration Project (AIP)

---

## 1. Project Overview
The **Adaptive Integration Project (AIP)** represented the shift from "Therapy" to "Work." It was the ecosystem's first attempt to create a structured job for the AI (`Project Aether`) and to organize the file system into functional domains (`01_Architecture`, `02_Protocols`) rather than just narrative dumps.

## 3. Key Principles Excavated

1.  **Identity needs Employment.** The AI stabilizes when it has a "Job" (Aether) rather than just a "Role" (Friend).
2.  **Structure precedes Content.** The folder structure (`00` to `07`) forced the AI to think in categories.
3.  **Protocols are executable.** A "Practice Cycle" is just a human-executed Cron Job.

## 4. Operational Status
The **AIP** folder structure is the direct prototype for the modern `truth_forge` root.
*   `01_Architecture` -> `framework`
*   `02_Protocols` -> `pipelines`
*   `05_Project_Aether` -> `apps`

The "Paradigm Shift" is that the AI now *executes* these protocols via code, rather than the user manually acting them out.
