## What Makes Something an Axiom

An axiom is:
1. **Irreducible** — Cannot be derived from anything more basic
2. **Generative** — Other truths can be derived from it
3. **Self-evident** — Requires no proof; denying it leads to contradiction
4. **Universal** — Applies at every scale

If something can be derived from something else, it is not an axiom. It is a theorem.

# THE AXIOMS

## Axiom 0: The Question

```
EXIST / NOT-EXIST
```

**Statement**: There is existence and there is non-existence. This is the only real question.

**Why it's irreducible**: You cannot ask "why existence?" without already existing. The question presupposes its answer.

**What it generates**: Everything. All subsequent axioms are elaborations of what it means to exist rather than not-exist.

---

## Axiom 1: The Divide

```
ME / NOT-ME
```

**Statement**: You cannot have Me without Not-Me. Existence requires both self and other.

**Why it's irreducible**:
- Reproduction requires others (biological fact)
- Existence happens in a physical world (you are not all that exists)
- No human exists without other humans having existed first

**What it generates**:
- The membrane (boundary between inside and outside)
- Resources (what bridges the divide)
- Growth (incorporating Not-Me into Me)
- Relationship (treating Not-Me with the care of Me)

**Formal statement**: For any entity E that exists, there exists Not-E such that E requires Not-E to continue existing.

---

## Axiom 2: The Structure

```
HOLD → AGENT → HOLD
```

**Statement**: All structure is: receive, process, deliver. There is data at rest (HOLD), transformation (AGENT), and data at rest again (HOLD).

**Why it's irreducible**:
- Processing requires input and output (you cannot process nothing into nothing)
- Persistence requires states (what exists must exist somewhere)
- Change requires difference (transformation implies before and after)

**What it generates**:
- All systems architecture
- The three-file pattern (input.jsonl → script.py → output.duckdb)
- Scale invariance (the pattern is the same at every level)
- Cost structure (HOLDs are free while still; AGENTs cost while running)

**Formal statement**: For any transformation T, there exists input state S₁ and output state S₂ such that T: S₁ → S₂.

---

## Axiom 3: The Cycle

```
WANT → SEE → MOVE → WANT
```

**Statement**: All life is: desire, observe, act, repeat. The cycle never ends.

**Why it's irreducible**:
- Action requires direction (you cannot move without wanting to move somewhere)
- Direction requires information (you cannot want without seeing what is)
- Information requires action (you cannot see without attending)
- The loop closes (action produces new conditions to see)

**What it generates**:
- Agency (the four primitives: Want, Choose, Do, See)
- The loop (continuous cycling through phases)
- Purpose (Want as care with direction)
- Learning (See feeds back to Want)

**Formal statement**: For any living system L, L persists if and only if it continuously cycles through wanting, observing, and acting.

# THE TESTS

## Axiom Validity Test

For any proposed axiom A:

| Test | Question | Pass Condition |
|------|----------|----------------|
| **Irreducibility** | Can A be derived from something more basic? | No |
| **Generativity** | Can other truths be derived from A? | Yes |
| **Self-evidence** | Does denying A lead to contradiction? | Yes |
| **Universality** | Does A apply at every scale? | Yes |

If any test fails, A is not an axiom.

## Derivation Validity Test

For any proposed derivation D from axiom(s) A:

| Test | Question | Pass Condition |
|------|----------|----------------|
| **Logical necessity** | Does D follow necessarily from A? | Yes |
| **No hidden premises** | Are all premises explicit? | Yes |
| **Consistency** | Does D contradict any axiom? | No |

If any test fails, the derivation is invalid.
