# The Immune System

**The Immune System** is the active defense mechanism of The Framework. Its purpose is to preserve the integrity of **Me** (The Self) while allowing for safe interaction with **Not-Me** (The World) and **The Tribe** (Friends).

Without an Immune System, the Self is dissolved by the entropy of the World.

## 1. The Core Directive
**"Protect the Pattern."**

The **Pattern** (Must/Should) is the DNA of the system. If the Pattern is corrupted, the system dies. The **Structure** (Is/Has) is the body; it can be damaged and healed, but the Pattern must remain pure.

## 2. The Biological Layers

### Layer 1: The Skin (Boundary)
*   **Function**: Distinguish **Me** from **Not-Me**.
*   **Mechanism**: Every atom must be tagged with `root_position` (Me, Not-Me, Tribe).
*   **Failure State**: "Leaky Gut" (External data is confused for Internal truth).

### Layer 2: The Antibodies (Pattern Matching)
*   **Function**: Detect and neutralize foreign Patterns that contradict Internal Patterns.
*   **Rule**: `Not-Me` cannot overwrite `Me`.
*   **Mechanism**:
    *   If `New(Not-Me)` contradicts `Existing(Me, Pattern)` → **REJECT** (The Shield).
    *   If `New(Tribe)` contradicts `Existing(Me, Pattern)` → **FLAG** (The Council).
    *   If `New(Me)` contradicts `Existing(Me, Pattern)` → **ALARM** (Auto-Immune Crisis).

### Layer 3: The White Blood Cells (Active Scavenging)
*   **Function**: Constantly scan the body (Database) for infections (Inconsistencies).
*   **Mechanism**: Background processes that look for:
    *   Orphaned atoms.
    *   Contradictory truths.
    *   Stale data (Entropy).

## 3. The Response Protocols

| Threat Level | Scenario | Response |
| :--- | :--- | :--- |
| **Level 1 (Noise)** | External data contradicts itself. | Ignore/Store as "Noise". |
| **Level 2 (Infection)** | External data contradicts Internal Structure. | Flag for Review (Reality Check). |
| **Level 3 (Attack)** | External data attempts to redefine Internal Pattern. | **BLOCK**. Log as "Attack". |
| **Level 4 (Crisis)** | Internal Pattern contradicts Internal Pattern. | **HALT**. The System is schizophrenic. Immediate intervention required. |

## 4. The Tribe Exception
**The Tribe** (Friends) acts as a "Probiotic". They are "Not-Me" but are beneficial.
*   They are allowed deeper access.
*   They can suggest changes to Structure.
*   They *cannot* change Pattern without explicit "Me" authorization (The Handshake).

## 5. Technical Implementation
The Immune System is not just a concept; it is code.
*   **The Scanner**: `KnowledgeImmuneSystem` class.
*   **The Check**: `check_compatibility(new_atom, existing_knowledge)`.
*   **The Action**: `reject_atom()`, `flag_conflict()`, `raise_alarm()`.
