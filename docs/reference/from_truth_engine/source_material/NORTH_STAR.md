## FOR AI AGENTS

**READ THIS FIRST.** This is the North Star. Everything flows from here.

### The Migration

We are mid-migration from an old architecture to a new one:
- **Old pattern:** Sprawling code, circular imports, broken dependencies
- **New pattern:** `HOLD -> AGENT -> HOLD` (clean, self-contained services)

### The AI Agent Walls

AI agents working here MUST go through walls:

**WALL 1: builder_service**
Before creating a script or service, use builder_service:
```python
from builder_service.service import build_service, build_script
code = build_service("my_service", purpose="What it does")
```

**WALL 2: schema_service**
Before querying a table, check schema_service:
```python
from schema_service.service import get_schema_service
schema = get_schema_service().get_schema("table_name")
```

**WALL 3: verification_service**
Before claiming something works, verify it:
```python
from verification_service.service import verify_service
result = verify_service("service_name")
```

**WALL 4: Do not delete what you don't understand**
Read the code. Ask the user. Understand the purpose.

### Why This Matters

Without walls:
- AI agents delete things they don't understand
- Code sprawls into circular dependencies
- Users get overwhelmed and quit

With walls:
- AI agents build correctly within constraints
- Code stays clean and self-contained
- Users transform safely within structure

**The walls are not restrictions. The walls are the structure that makes freedom possible.**

### For AI Agents Working Here

1. **Ask the brain first:** `curl http://localhost:8000/next`
2. **Don't create files in old patterns** - follow `HOLD -> AGENT -> HOLD`
3. **Keep code self-contained** - no external module dependencies
4. **Register tasks** in `Primitive/staging/migration_tasks.jsonl`
