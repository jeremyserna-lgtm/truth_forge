## WHAT (Specification)

### The Loop

The fundamental work pattern through time.

```
WANT → CHOOSE → EXIST:NOW → SEE → HOLD → MOVE
  ▲                                      │
  │                                      │
  └──────────────────────────────────────┘
```

| Phase | What It Is | What You Build |
|-------|------------|----------------|
| **Want** | Care has a direction | Backlog system |
| **Choose** | Exist:Now is a verb, not a fact | Planning service |
| **Exist:Now** | The doing, the membrane | Pipeline tracker |
| **See** | Cross the Show/See membrane | Observers, queries |
| **Hold** | Membrane = Hold + Agent | DuckDB local, BigQuery cloud |
| **Move** | Boundary crossing → next Want | Atom extraction, bridges |

**Move becomes the next Want. The loop never ends.**

### The Four Systems

Four systems. One loop.

```
PLAN ──────► BACKLOG ──────► EXIST:NOW ──────► ATOMS
  ▲                                              │
  │                                              │
  └──────────────────────────────────────────────┘
```

| System | Role in Loop | Temporal Function |
|--------|--------------|-------------------|
| **Planning** | Decides what should exist | Future → Present |
| **Backlog** | Holds what wants to exist | Waiting (queue) |
| **Exist:Now** | The doing | Present (active) |
| **Atoms** | Final form of what existed | Present → Permanent |

**Everything ends in knowledge atoms. Atoms inform next plan.**

### The Insight

> "Whatever I do, regardless of what it is, ends in knowledge atoms."

This is the key. Knowledge Atoms are not a feature. They are the **terminal form of all existence in time**.

- Write code → atoms about code
- Have conversation → atoms about what was said
- Make decision → atoms about the decision
- Build system → atoms about the system

**Everything that passes through Exist:Now becomes atoms. Atoms are how existence persists through time.**

### The Bridge (Connection Through Time)

How things cross from one temporal state to another:

```
Source Adapter → Crossing → Target Adapter
```

| Component | Temporal Role |
|-----------|---------------|
| **Source Adapter** | Speaks the past state's language |
| **Crossing** | The transformation (the present moment) |
| **Target Adapter** | Speaks the future state's language |

**Without bridges, there are only frozen moments. Bridges connect time.**

Bridges in the system:
- Local ↔ Cloud (now ↔ persistent)
- Human ↔ Technology (intent ↔ execution)
- Thinking ↔ Implementation (plan ↔ code)
- Doing ↔ Knowing (completion → atoms)

### The Recursion (Self-Reference Through Time)

The pattern applies to itself across time:

| Level | What It Means |
|-------|---------------|
| **Function** | The thing does X |
| **Identity** | The thing IS X |
| **Self-reference** | The thing can X itself |

**Signs of recursion**: "We need a separate system to track X" → X should track itself.

**Stage 5** = System sees itself seeing. That's recursion through time. Past observes present observes future.

#### The Recursion Completes When

```
Aspirational (future):  Contracts describe what SHOULD exist
Descriptive (present):  Contracts describe what DOES exist
Complete (convergence): No gap between the two
```

**The map becomes the territory when every action leaves a trace.** The trace IS the temporal persistence.

### The Membrane Stack (Transitions Through Time)

Every transition in the loop is a membrane—a moment of crossing:

```
PLAN ──[membrane]──► BACKLOG
       (future becomes queue)

BACKLOG ──[membrane]──► EXIST:NOW
         (queue becomes action)

EXIST:NOW ──[membrane]──► ATOMS
           (action becomes record)

ATOMS ──[membrane]──► PLAN
       (record becomes future)
```

Each membrane is a temporal boundary:
- **Hold**: What persists at this moment
- **Agent**: What transforms this moment into the next

### The Entropy

Time has direction. Entropy increases.

```
Order → [TIME] → Disorder
         │
    (unless work)
```

The loop is **anti-entropic work**. It creates order:
- Chaos (external signals) → Order (atoms)
- Noise (raw data) → Signal (patterns)
- Forgetting (entropy) → Remembering (record)

**The system exists to fight entropy. The loop is how.**

### The Rhythm

The loop has natural periods:

| Period | What Happens |
|--------|--------------|
| **Moment** | Single exist-now (atomic action) |
| **Session** | Continuous work (live-now) |
| **Cycle** | Plan → Do → Record (complete loop) |
| **Evolution** | Patterns emerge across cycles |

The rhythm isn't imposed. It emerges from the structure operating through time.
