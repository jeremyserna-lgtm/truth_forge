## The Operational Definitions

The Framework does not deal in abstract ideals. It deals in **Operational Primitives**.

### 1. Care (The Direction)
**Primitive**: `WANT` (from Agency)

Care is not a feeling. It is a vector. It has a source and a direction.

| Abstract | Operational | Implementation |
|----------|-------------|----------------|
| "I care about X" | "I allocate resources to X" | **Backlog / Prioritization** |

**The Test**: If you say you care about X, but X is not in the Backlog or getting resources, you do not actually care about X. The system reveals the truth of your care through resource allocation.

### 2. Truth (The Observation)
**Primitive**: `SEE` (from Agency)

Truth is not a static fact. It is an active observation crossing a membrane.

| Abstract | Operational | Implementation |
|----------|-------------|----------------|
| "X is true" | "I have a record of seeing X" | **Structured Logging / Source IDs** |

**The Test**: If it is not logged, it was not seen. If it was not seen, it is not True to the system. Truth requires a record (`source_id`, `timestamp`).

### 3. Meaning (The Persistence)
**Primitive**: `EXIST-NOW` (from Existence)

Meaning is not a definition. It is the continuous choice to exist.

| Abstract | Operational | Implementation |
|----------|-------------|----------------|
| "X has meaning" | "X persists through time" | **Idempotency / Resilience** |

**The Test**: If the system crashes and stays down, it has lost its meaning. Meaning is the persistence of the pattern through time.

## The Value Loop

```
CARE (Want) → TRUTH (See) → MEANING (Exist)
```

1.  **Care** directs the system (Want).
2.  **Truth** validates the system (See).
3.  **Meaning** sustains the system (Exist).

If any link breaks, the system loses value.
- Care without Truth is delusion.
- Truth without Meaning is data.
- Meaning without Care is inertia.
