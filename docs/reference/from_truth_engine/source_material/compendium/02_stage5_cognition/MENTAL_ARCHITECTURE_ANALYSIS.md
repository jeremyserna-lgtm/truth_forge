## IV. Identified Loops (Recurring Patterns)

Based on semantic analysis of repeated themes across the corpus:

### The Seeing-Being-Seen Loop
**Pattern**: Jeremy sees others → offers what he sees → hopes to be seen in return → experiences asymmetry → continues seeing anyway

**Emotional Signature**: Trust + Anticipation + (latent Sadness)

**Evidence**:
> "I live in plain sight, hoping others will see me."
> "I can see their system... but they can't see mine with the same clarity."

### The Building-Through-Breakdown Loop
**Pattern**: Crisis occurs → building intensifies → meaning is forged → structure emerges → new baseline established

**Emotional Signature**: Fear → Anger → Anticipation → Positive → Joy

**Evidence**: The temporal arc shows this clearly - highest volume during lowest polarity week, followed by gradual recovery to breakthrough.

### The Truth-Furnace Loop
**Pattern**: Raw truth arrives → heat applied (processing) → meaning forged → delivery with care

**Emotional Signature**: Negative (input) → Anger (heat) → Anticipation (forging) → Trust (delivery)

**Evidence**:
> "I take truth and forge meaning and deliver it with care."

### The Asymmetric Care Loop
**Pattern**: Jeremy invests in relationship → sees other fully → other cannot reciprocate at same depth → accepts asymmetry → continues investing

**Emotional Signature**: Joy + Trust + (background Sadness rarely surfacing)

**Evidence**: Sadness is only 0.3% of total emotions despite clear awareness of relational asymmetry.

## VII. Methodological Notes
