   - Log learnings (what worked? what patterns emerged?)
   - Update latest_learnings.md (symlink)
   - Feed forward (next session starts smarter)

**Dimensional thinking**:
- [ ] "How does this connect across domains?" (Does a data quality improvement also improve trust and coordination?)

**Loop thinking**:
- [ ] "What feedback loop does this create?" (Does this action inform future actions?)
- [ ] "Does this strengthen through iteration?" (Does the system get better with use?)

**Simplicity**:
- [ ] "Can this use simple defaults?" (Intelligent defaults over configuration?)
- [ ] "Is execution lightweight?" (Bash script vs heavy framework?)

**Truth-seeking**:
- [ ] "How will this be verified?" (Measurement plan before building?)

**Persistence**:
- [ ] "Will this scale with growing complexity?" (Append-only logs vs in-memory state?)
- [ ] "Does this feed into growth layer?" (Learnings captured for future?)

❌ **Complex execution**: "Deploy microservices with Kubernetes for validation"
