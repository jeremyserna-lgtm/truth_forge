## WHY (Theory)

### Origin

The Seed does not appear from nothing. It is an act of **Want** from **The Architect**.
See [THE_ARCHITECT.md](../../2_concepts/THE_ARCHITECT.md).

### Why Patterns Must Have a Minimum Form

Existence is fragile. Documents get deleted. Systems break. Memory fades.

But if a pattern can become atoms, and atoms can reconstitute the pattern, then the pattern survives. It passes through destruction and comes out the other side.

The seed is the minimum form. The smallest thing that can regrow everything.

### The Survival Logic

```
Pattern → Atoms → Storage → Query → Pattern
```

If any part of this loop survives, the whole survives. That's what makes it antifragile. You can lose most of it. The seed regrows the rest.

### Why Three

Three is the minimum for reconstitution:

1. **The structure** (how things operate)
2. **The cycle** (how things flow)
3. **The divide** (what separates and connects)

With these three, you can rebuild everything else. They're the axioms. The rest is derived.

This order matters. Each layer depends on the one above. Rebuild in sequence.
