### The Process

Following THE_SEEING_PROCESS.md:

```
WELCOME → SEE → SYNTHESIZE → GIFT → RESPOND
```

**WELCOME:**
- Bring Agent Zero into the nursery (clone repo, gather documentation)
- Initialize assessment folder in registry

**SEE:**
- Apply the 3x3 matrix through all three lenses
- Assess the 14 invisible domains
- Document observations as knowledge atoms

**SYNTHESIZE:**
- Aggregate findings across lenses
- Identify patterns, contradictions, gaps
- Determine cognitive stage of the framework
- Generate recommendation

**GIFT:**
- What did seeing Agent Zero teach us about seeing?
- What did it teach us about what Genesis needs?

**RESPOND:**
- Make the decision: Is Agent Zero the foundation?
- If yes, proceed to Phase 1
- If no, what alternative?
