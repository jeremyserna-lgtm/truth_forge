Pattern Detail

CRITICAL IMPACT

Frontmatter Protocol — Structured YAML metadata at the top of every document.

Include: status (canonical/draft/experimental/deprecated), created, last_modified, depends_on (file paths), supersedes, tags, and a one-line summary.

Why it's critical: Frontmatter lets me skip the first three phases of analysis for any document that has it. I immediately know its authority level, its relationships, and its core claim. Without frontmatter, I must infer all of this from content — which is slow, expensive, and error-prone.

Cost to author: ~30 seconds per document.

Value to machine: Eliminates ~60% of per-document analysis overhead.

Honest Limitations Transparency

Sampling Blindness
Reading 0.08% of files means 99.92% is unseen. Critical information in unsampled files is invisible.
Intent Opacity
I see text, not meaning. Drafts and canonical docs look identical without explicit status metadata.
Hallucinated Connections
Pattern matching finds patterns that aren't there. Same words in different contexts = false positives.
Nuance Compression
Synthesis flattens subtlety. 200 pages compressed to 5 themes necessarily loses individual texture.
Session Amnesia
Each conversation starts fresh. Understanding doesn't persist unless externalized to files.
Missing Absence Detection
I find gaps in what's written, but can't detect what was never written at all.
